# Source & Component Registry

Registro institucional de fontes externas (componentes UI/headless, ícones, fontes, ilustrações, charts, maps, data grids, motion, acessibilidade, Design Systems e inspiração) — substitui bookmarks pessoais. Ver canônico §11.

Funil de promoção: `Discovered → Reviewed → Approved Reference → Prototype Candidate → Production Approved`.

Um arquivo por fonte/componente, usando o template abaixo (canônico §11.2):

```yaml
name:
url:
type:
technology: []
license:
license_evidence_url:
commercial_use:
attribution_required:
obligations:
use_for: [reference, prototype, production-candidate]
status:
design_reviewed_by:
technical_reviewed_by:
last_reviewed:
notes:
```

"Grátis" não significa liberado para uso comercial. Dev valida risco técnico/dependência; João registra licença e obrigações; Aline valida qualidade/aplicabilidade.
